# 管理后台管理台设计

## 目标

把现有只读运营监控扩展为安全管理台，支持总览、用户管理、平台模型接入、用户模型查看和管理员审计。

## 页面结构

- 总览：保留现有统计卡片、趋势图和事件流。
- 用户管理：搜索用户，查看状态/积分/项目数/模型数，编辑昵称，重置密码，冻结/恢复账号。
- 模型接入：维护平台模型目录（类型、服务商、模型名、Base URL、启用状态），不保存或返回明文 Key。
- 审计日志：展示管理员操作、目标账号、操作结果和时间。

## 安全边界

- 管理员继续由 `ADMIN_EMAILS` 白名单控制。
- 删除采用冻结/软删除，不擦除项目和交易记录。
- 重置密码只接收新密码，不返回旧密码。
- 用户模型 API Key 只返回掩码；平台模型目录不存密钥。
- 所有写操作写入审计日志。

## 数据兼容

旧用户默认 `active: true`，旧数据没有模型目录或审计日志时按空数组处理。
